## RackNerd 跑 Windows 是什么形态？自己装，授权自理

先把最容易踩坑的认知问题解决掉：RackNerd 卖的 KVM VPS，默认镜像只有 Linux，官方不附带 Windows 授权，面板里也没有“一键装 Windows”的按钮。想跑 Windows，路径是在控制面板挂载自己准备好的 ISO，再通过 VNC 控制台手动装系统。

这件事拆开是两层。镜像本身好解决：微软官网提供 Windows Server 2019/2022 的评估版 ISO，免费下载，装好后可以先正常用 180 天，之后要么用自己买的授权转正，要么重装。第二层是细节坑：ISO 要选集成了 VirtIO 驱动的版本，否则安装程序认不到 KVM 虚拟硬盘，第一次自装卡住，多半就卡在这一步。

装完还有一件必须做的事：改 RDP 端口、设强密码。公网上扫 3389 端口的流量非常勤快，裸奔的远程桌面撑不了几天就会开始被撞库。OliveVPS 这类预装商家默认就把 RDP 放在非标准端口，不是人家有洁癖，是整个行业被扫描器教育出来的共识。

如果你完全不想碰这些，直接跳到后面的对比部分；愿意花半小时换每年省一百多美元，接着往下看。
